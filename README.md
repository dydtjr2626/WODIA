# Plan · Do · See 다이어리

계획 → 실행 → 회고를 서버 DB(SQLite)에 저장하는 개인 다이어리. 로그인 없음.
> 지금은 로그인이 없어 링크를 아는 사람은 누구나 볼 수 있습니다. 남이 봐도 괜찮은 내용만 넣으세요.

## 실행
```
node server.js      # Node 22.5+ (내장 node:sqlite 사용, 설치할 패키지 없음)
→ http://localhost:3000
```
DB 파일: `data/pds.db` (처음 실행하면 빈 상태로 시작해요. 계획과 할 일은 직접 입력합니다)

## 화면
- **달력(메인)**: 주 단위 일정 · 카드를 누르면 오른쪽에서 시작 시각/소요 시간/막힘 사유 기록, 완료·건너뛰기·완료 취소
- **목록**: 검색 · 상태/우선순위/태그/계획 필터 · 정렬(기준과 같을 때의 보조 기준을 화면에 표시)
- **계획**: 수정 이력(최초 계획 v0 보존)
- **오른쪽 주간 회고**: 숫자를 누르면 근거가 된 할 일 목록(어디서 늦고 빨랐는지) 표시 / **아래 배너**: 개선점 1가지를 계획에 반영
- **저장 버튼**: 비우면 달력 전체, 날짜(YYYY-MM-DD)를 넣으면 그 날의 상세 목록 JSON (`/api/export?scope=all`은 전체 원본 덤프)

## 추가 기능
- **오른쪽 패널 탭**: 주간 / 월간 회고 / 추이(주별 완료율 · 시간 차이 · 연속 운동 일수)
- **막힘 사유 통계**, **예상 시간 보정 제안**(최근 4주, 같은 일 3번 이상 · 평균이 5분 이상 다를 때 → 앞으로의 예상 시간 일괄 변경)
- **운동 기록**: 운동 할 일에 세트·무게·횟수와 컨디션(1~5) 저장
- **알림**: 왼쪽 🔔 (탭이 열려 있는 동안 할 일 시각에 브라우저 알림)
- **삭제 되돌리기**, **다른 날짜로 복제**, **전날 일정 복사**
- **다크 모드**: 왼쪽 아래 ☾/☀ (모바일 화면은 아직 신경 쓰지 않음)
- **백업**: 계획 화면에서 전체 백업 내려받기 / 불러오기 (불러오면 현재 데이터가 교체됨)

## 짧은 확인 방법
1. **어디로 가나요?** https://yong-wodia.onrender.com (무료 서버라 한동안 쓰지 않으면 잠들어서 첫 접속은 30초~1분 걸릴 수 있어요)
2. **세 단계 안에서 무엇을 하나요?** ① 카드 클릭 → ② 소요 시간 입력 → ③ 「완료」 (새로고침 후에도 유지)
3. **무엇이 보이면 통과인가요?** 완료 체크 + 오른쪽 회고의 완료 수 +1, 새로고침해도 그대로
4. **안 될 때 무엇이 보이나요?** 화면 아래 검은 토스트에 이유(예: "건너뛴 사유를 입력해 주세요")가 표시됨. 서버가 잠들어 있으면 처음에는 화면이 늦게 뜸

## 구현 가정 (원하면 바꿀 수 있음)
- 금요일은 기본 휴식. 평일 운동을 건너뛰면 어깨→가슴→등 순서를 유지한 채 하루씩 뒤로 밀리고, 주말 삼두·이두는 밀리지 않으며 다음 주로도 넘어가지 않음
- 데이터 스키마: `contracts/pds-schema-v2.json`
